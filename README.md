# Database Management Systems (DBMS)

This repository contains my Database Management Systems (DBMS) coursework, SQL queries, laboratory assignments, practice problems, and database projects using **MySQL**.

## Topics Covered

- SQL Basics
- DDL, DML and DCL
- Constraints
- Joins and Subqueries
- Aggregate Functions
- Functional Dependency
- Normalization
- ER Diagrams
- Indexing
- Hashing
- Views and Materialized Views
- Transactions
- Triggers and Stored Procedures
- Partitioning
- Database Projects

## Tools & Technologies

- **Database Management System:** MySQL
- **Database GUI:** MySQL Workbench
- **Local Server Environment:** XAMPP
- **Command-Line Interface:** Command Prompt (CMD)
- **Version Control:** Git & GitHub

## Purpose

This repository is maintained to organize my DBMS learning materials, strengthen my understanding of relational databases, and improve my SQL programming skills.

It serves as a personal reference for academic revision, laboratory work, problem-solving practice, and future database development projects.

## Learning Goals

- Understand relational database concepts and architecture.
- Write SQL queries to create, retrieve, update, and delete data.
- Design databases using ER diagrams and normalization techniques.
- Understand functional dependencies, indexing, and hashing.
- Manage database transactions and maintain data integrity.
- Work with MySQL using XAMPP, MySQL Workbench, and Command Prompt.
- Apply database concepts to practical projects.
- Maintain clean, organized, and reusable SQL scripts.

## Development Environment

All database exercises and projects are developed using MySQL.

Depending on the task, I may use XAMPP to run a local MySQL-compatible database server, MySQL Workbench for graphical database management, or Command Prompt to execute SQL commands through the MySQL command-line client.
