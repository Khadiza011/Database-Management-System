
# Database Normalization

This section covers database normalization techniques using **MySQL** to reduce data redundancy, improve data integrity, and organize relational database structures.

## Topics Covered

- Introduction to Normalization
- First Normal Form (1NF)
- Second Normal Form (2NF)
- Third Normal Form (3NF)
- Boyce-Codd Normal Form (BCNF)
- Functional Dependencies
- Partial and Transitive Dependencies
- Database Anomalies (Insert, Update, Delete)


## Tools & Technologies

- MySQL
- MySQL Workbench
- Command Line
- Git & GitHub

## 🗃️ Database Used

`normalization_db`

## Learning Objectives

- Understand different normal forms.
- Reduce data redundancy.
- Identify functional dependencies.
- Eliminate database anomalies.
- Design efficient and well-structured relational databases.

## Purpose

This section is maintained to develop practical knowledge of database normalization through SQL examples, relational database design, and academic exercises.
