# SQL Basics

This section contains my SQL fundamentals, practice queries, and examples using **MySQL / MariaDB**. It covers the essential concepts required to retrieve, manipulate, and process data in relational databases.

## Topics Covered

- Introduction to SQL and Database Creation
- Inserting and Retrieving Data
- Updating and Deleting Data
- SQL Operators
- SQL Aliases and Expressions
- SQL Conditions and CASE Expressions
- SQL String Functions
- SQL Numeric and Mathematical Functions
- SQL Date and Time Functions

## Tools & Technologies

- **Database Management System:** MySQL / MariaDB
- **Local Server Environment:** XAMPP
- **Database Interface:** phpMyAdmin
- **Command-Line Interface:** Command Prompt (CMD)
- **Version Control:** Git & GitHub

### Database Fundamentals
- Creating databases and tables
- Understanding columns, data types, and primary keys
- Selecting and working with databases

### Data Manipulation and Retrieval
- Inserting single and multiple records
- Retrieving all or selected columns
- Filtering records using `WHERE`
- Updating and deleting records safely
- Sorting and limiting query results

### SQL Operators and Expressions
- Arithmetic and comparison operators
- Logical operators such as `AND`, `OR`, and `NOT`
- `BETWEEN`, `IN`, `LIKE`, and `IS NULL`
- Column aliases and table aliases
- Conditional expressions using `CASE` and `IF()`

### SQL Functions
- String functions such as `CONCAT()`, `SUBSTRING()`, `UPPER()`, and `LOWER()`
- Numeric functions such as `ROUND()`, `ABS()`, `POWER()`, and `SQRT()`
- Date and time functions such as `CURDATE()`, `NOW()`, `DATE_FORMAT()`, and `DATEDIFF()`

## Database Used

The SQL exercises in this section primarily use the `university_db` database and its `students` table.

These examples demonstrate database creation, data retrieval, filtering, modification, and the use of built-in SQL functions.

## Learning Objectives

- Build a strong foundation in SQL.
- Understand basic relational database operations.
- Write clear and structured SQL queries.
- Retrieve and filter records using different conditions.
- Apply built-in functions to strings, numbers, and dates.
- Practice SQL using MySQL / MariaDB.
- Maintain organized SQL scripts for revision and future reference.

## Important Notes

- Execute the SQL files in the appropriate order when following the complete practice sequence.
- Some queries depend on the database and tables created in earlier files.
- Repeated `INSERT` operations may cause duplicate primary key errors.
- Always check the `WHERE` condition before executing `UPDATE` or `DELETE`.
- The output of date and time functions depends on the current system or database server time.
