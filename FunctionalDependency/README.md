# Functional Dependency

This section covers Functional Dependency concepts in relational database design using **MySQL**.

## Topics Covered

- Functional Dependency (FD)
- Determinants and Dependent Attributes
- Simple and Composite Functional Dependencies
- Super Keys and Candidate Keys
- Primary Keys and Alternate Keys
- Prime and Non-Prime Attributes
- Composite Keys
- Attribute Closure

## Tools & Technologies

- MySQL
- MySQL Workbench
- Command Line
- Git & GitHub

`fd_practice_db`

## Learning Objectives

- Understand Functional Dependencies.
- Identify Candidate Keys and Super Keys.
- Understand Determinants and Attribute Closure.
- Identify Prime and Non-Prime Attributes.
- Build a foundation for Database Normalization.
